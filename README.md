## Repository Guide
- 'Final_NAO' contains the final, complete implementation of our project.
- 'FaceIdentifier' was our first case of both detecting and identifying a face. This script was iterated over and incorporated into the final program. This folder contains the 3 developments and models neccesary to run them. 
- 'HaarDetectTest' is the earliest script we created, and contains a rudimentary facial detection method.
